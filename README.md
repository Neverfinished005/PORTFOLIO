# Singularity OS // TON 618

An immersive 3D event horizon portfolio and interactive black hole physics experience built with React 19, Three.js, React Three Fiber, GLSL raymarching shaders, and Tailwind CSS.

---

## Features

- **Relativistic 3D Black Hole Raymarching**: Custom GLSL shader with gravitational lensing, accretion disk turbulence, photon sphere glow, and Doppler blue-shift.
- **Audio-Reactive Accretion Disk**: Real-time Web Audio API frequency analysis driving procedural shader uniforms and acoustic redshift.
- **Warp Dive Sequence**: Dynamic relativistic plunge past the event horizon into the Singularity Core workstation.
- **360° Free-Cam Orbit**: Interactive camera orbital controls with inertia damping and precision custom cursor.
- **Zero-AI Slop Engineering Terminal**: Minimalist developer dashboard displaying tech stack, featured repositories, and direct contact dispatch.
- **High-Performance Architecture**: 60fps across desktop, laptops, tablets, and mobile with low-power shader tiering.
- **Hardened Security**: Content Security Policy (CSP), sub-resource protections, noopener link isolation, and zero vulnerable dependencies.

---

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **3D & Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation**: Motion (`motion/react`)
- **Styling**: Tailwind CSS v4, JetBrains Mono, Space Grotesk
- **Audio Engine**: Native Web Audio API (procedural synthesizers & biquad filters)

---

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview production build locally
npm run preview
```

---

## Security & Privacy

- Strict Content Security Policy (`CSP`) restricting unauthorized scripts, network egress, and clickjacking.
- Isolated external links with `rel="noopener noreferrer"`.
- No client-side secret leakage or exposed environment variables.
